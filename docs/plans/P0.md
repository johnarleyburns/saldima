## Sequencing

2. Scaffold, then CI — CI must run the suite before more code lands.

## Exit criteria

- [ ] All four spike checks pass locally and on staging on a real 20 MB book:
      introspected schema reads account tree/register from DO SQLite; import +
      export under 100 MB and 10 s with desktop GnuCash 5.x opening the export;
      warm register < 20 ms CPU; `wrangler dev`, a workerd Vitest test and one
      Playwright test pass locally and in CI.
- [ ] `pnpm dev`, workerd Vitest and Playwright are green in CI on a PR.
- [ ] Hello-world reached staging **after owner approval** (agent never deploys).
- [ ] Coverage >= 90% lines on `packages/*`; license, SPDX and actionlint gates
      required.
- [ ] iOS can pin a web commit for money/GUID vectors.

## Risks and open questions

- **Design tab not in the provided Markdown export.** The code layout above is
  inferred from the Architecture section and the spec's package names. Confirm
  against the Design tab before P1.
- **ESLint vs Biome.** The P0 backlog says "ESLint rules"; the CI table says
  Biome. Decision: Biome for lint/format plus small TypeScript-AST gates for the
  money/random/clock rules, so the rules are enforced without maintaining two
  linters. Revisit if the Design tab specifies otherwise.
- **Spike fixture.** Without the owner's real book, only synthetic fixtures can
  run; the real-GnuCash oracle acceptance cannot pass. Issue #6 stays blocked.
- **Cloudflare Containers in local dev.** `pnpm dev` needs Docker for the
  converter. The smoke suite must pass without the converter (XML path marked
  as a runtime test) until the container image exists.
- **Action pinning.** Actions are pinned to commit SHAs; Dependabot keeps them
  current. First pins are recorded in `ci.yml`.
- **License scan scope.** The gate scans production dependencies with a strict
  MIT/BSD/Apache/ISC/0BSD/CC0 allowlist. Dev tooling is excluded because it never
  ships; Vite currently pulls MPL-2.0 `lightningcss` into the test runner. This
  is recorded here rather than silently allowlisted; revisit before the App
  Store build (P5).
